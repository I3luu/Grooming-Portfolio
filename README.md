# Kacey Studies Coats

A bright, playful portfolio built with React, TypeScript, Vite and Tailwind.

Background, title text, buttons and project gallery use components from [ReactDrops](https://reactdrops.dev).

All personal content lives in `src/content.ts` (placeholders are marked `TODO`). Photos go in `public/images/`.

## Running locally

```sh
npm install
npm run dev
```

Build with `npm run build`. Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml` (set Pages source to "GitHub Actions").
